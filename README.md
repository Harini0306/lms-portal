# LMS Portal

A full-stack Learning Management System built with **Java, Spring Boot, React, and MongoDB**.

## Project Goal

Develop a platform where students can access courses, track learning progress, and complete assessments, while instructors manage course content and administrators manage the platform.

## Technology Stack

- **Backend:** Java, Spring Boot, Spring Web
- **Database:** MongoDB Atlas
- **Frontend:** React, JavaScript, HTML, CSS
- **Build Tool:** Maven
- **Version Control:** Git and GitHub

## Current Progress

- [x] Spring Boot project initialized
- [x] Backend application starts successfully
- [x] Health-check REST API implemented
- [ ] MongoDB Atlas integration
- [ ] User registration and authentication
- [ ] Role-based access control
- [ ] Course management
- [ ] Student enrollment and progress tracking
- [ ] React frontend

## Learning Objectives

Build practical skills in Java, REST API development, Spring Boot, NoSQL database design, frontend integration, authentication, and full-stack application development.
